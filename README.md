## Моя идея для проекта:
Трекер отходов с компьютерным зрением для мусорных баков.

Я реализую код с компьютерным зрением, для определения мусора и его вида, чтобы помогать людям правильно распределять мусор.

## Тип моего проекта:
работа с компьютерным зрением
